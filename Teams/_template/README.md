# Teams folder structure

Each team lives in its own subfolder named after the team. Inside the folder, files use consistent generic names so paths are predictable across teams.

```
Teams/
├── _template/                ← this folder; copy team.md / matchup.md to start
│   ├── README.md             (this file)
│   ├── team.md               (blank team template)
│   ├── matchup.md            (blank post-match analysis template — DOUBLES)
│   ├── matchup-singles.md    (blank post-match analysis template — SINGLES: lead 1, bring 3)
│   └── matchup-prompt.md     (copy/paste fill-in for starting a post-match chat)
└── <Team Name>/
    ├── team.md               (the team in structured markdown — required)
    ├── team.txt              (optional: original raw notes; safe to delete after team.md is verified)
    ├── strategy.md           (playbook generated by Claude — created on demand)
    └── matchups/             (post-match analyses, one file per opponent archetype)
        └── <archetype>.md
```

## Adding a new team

1. Create a new folder: `Teams/<Team Name>/`
2. Copy `_template/team.md` to `Teams/<Team Name>/team.md`
3. Fill in the 6 Pokemon (see formatting rules in `team.md`)
4. Ask Claude for a strategy doc — it will be saved as `Teams/<Team Name>/strategy.md`

## Adding a post-match analysis

After a tournament match, give Claude the opponent's 6, their bring, their leads, and what you brought/led. **Open `_template/matchup-prompt.md`, copy the prompt block, fill in the fields, and paste into a fresh Claude conversation.** Claude will produce a matchup file at `Teams/<Team Name>/matchups/<archetype>.md` using `_template/matchup.md` as the structure. Filename convention: lowercase, hyphenated, archetype-driven (`rain-ghost-froslass-ceruledge.md`, not the opponent's username).

## Format rules (recap from team.md)

- Stats and EVs are slash-separated in **HP / Atk / Def / SpA / SpD / Spe** order
- Moves are slash-separated in slot order (4 moves)
- Leave a field blank if unknown — do not delete the bullet
- The team folder name should match the team identity (e.g. "Mega Greninja", "Sun Offense", "Trick Room Stall")
- Set **Format** in the Notes section to `doubles` (default), `singles`, or `both`. Doubles = bring 4 of 6, 2 active; singles = bring 3 of 6, lead 1. For singles teams use the `Lead:` / `Bring three:` note fields instead of the doubles `lead pair` / `back pair`, and analyze with `matchup-singles.md`.

## Why this format

Markdown over XLSX: faster for Claude to read (no Python required) and editable in any text editor. Slash-separated values keep stats and EVs visually compact. Per-team folders keep `team.md`, `team.txt`, and `strategy.md` together as a single unit.
